# Afterpay J27 — Central da Operação

Site estático preparado para deploy na Vercel. O conteúdo principal está em `index.html` e inclui os estilos, scripts, módulos e animações dentro do próprio arquivo.

## Publicar pelo GitHub + Vercel

1. Extraia este ZIP no computador.
2. No GitHub, crie um repositório novo chamado `afterpay-j27-central` (pode ser privado; o site publicado na Vercel continuará acessível pelo link público).
3. Envie `index.html`, `vercel.json` e este `README.md` para a raiz do repositório.
4. Entre em https://vercel.com/ e escolha **Add New → Project**.
5. Importe o repositório `afterpay-j27-central`.
6. Para este site estático, deixe Framework Preset como **Other** e não configure Build Command nem Output Directory; faça o deploy.
7. Abra o endereço `*.vercel.app` fornecido pela Vercel e teste em uma janela anônima e no celular.

## Acesso e privacidade

O site fica acessível a qualquer pessoa que tenha o endereço público. Não o adicione a vitrines/feed públicos. Atenção: um link não listado não é uma proteção de acesso; qualquer pessoa com o endereço pode encaminhá-lo a terceiros. Não inclua dados pessoais ou materiais que devam ficar restritos.
